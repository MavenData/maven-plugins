# Maven report builder

Follow [the shared live preview workflow](references/workflow.md). This is the
same maintained workflow delivered to all MCP clients. Maven remains the source
of truth; open its authenticated web viewer in the available sidebar or browser
while editing the same draft through the consolidated report tool.

Author supported HTML source directly; import complete existing artifacts through
the supported import operation.
Preserve frozen branding, binding provenance, and runtime contracts returned by
report operation=read options.action=inspect_context. Use governed queries for every live value.
Untraceable imported numbers must remain explicitly static. Do not add external
fetches, arbitrary warehouse queries, CDNs, or runtime package installation.

For geometry use Maven's vendored D3 Geo + TopoJSON and validated identifiers.
Reports, presentations, and custom layouts share the same draft lifecycle.
Presentations scroll by default; a request for slides or a deck selects paged mode.
